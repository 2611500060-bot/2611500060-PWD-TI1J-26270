## Validasi HTML
- Berkas yang divalidasi: `index.html`
- Galat yang ditemukan: 
1.Baris 1: DOCTYPE tertulis dua kali → harus <!DOCTYPE html>.
2.Baris 50: URL pada href tidak menggunakan tanda kutip dengan benar.
3.Baris 50: Setelah URL kurang tanda >.
Tag <a> dan <p> menjadi tidak beraturan/tertutup salah, sehingga muncul banyak error lanjutan.

- Perbaikan yang dilakukan:
 1.Mengubah <!DOCTYPEDOCTYPE html> menjadi <!DOCTYPE html>.
2.Memperbaiki penulisan link <a> dengan memberi tanda kutip pada URL.
3.Menambahkan tanda > setelah URL.
4.Memastikan tag <a> dan <p> dibuka dan ditutup dengan benar.
5.Menyimpan file lalu menjalankan validasi ulang sampai error berkurang/hilang.

- Hasil validasi akhir: Document checking completed. No errors or warnings to show.
