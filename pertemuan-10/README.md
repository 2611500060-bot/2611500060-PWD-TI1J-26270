# PERTEMUAN 10

Pemrograman Web Dasar

Pada pertemuan 10 ini saya mempelajari cara membuat database dan tabel menggunakan phpMyAdmin. Saya juga belajar mengatur struktur tabel sesuai dengan ketentuan yang ada di modul.

Database yang saya buat bernama "db_pwd_2611500060" dan memiliki tabel bernama "tbl_kontak_2611500060".

Di dalam tabel tersebut terdapat 9 kolom, yaitu:

1. id
2. nama
3. email
4. semester
5. tanggal
6. jenis_pesan
7. minat
8. prodi
9. pesan

Setiap kolom memiliki tipe data dan panjang karakter yang berbeda sesuai dengan kebutuhan penyimpanan data. Kolom "id" digunakan sebagai Primary Key dan sudah menggunakan AUTO_INCREMENT agar nomor ID bertambah secara otomatis.

Setelah membuat tabel, saya melakukan pemeriksaan menggunakan menu Structure dan perintah SQL berikut:

DESCRIBE tbl_kontak_2611500060;

Pemeriksaan ini dilakukan untuk memastikan nama kolom, tipe data, Primary Key, dan atribut lainnya sudah sesuai dengan rancangan pada modul.

Saya juga mencoba memasukkan data ke dalam tabel melalui menu Insert, seperti nama, email, semester, tanggal, jenis pesan, minat, prodi, dan pesan.

Kesimpulan:

Dari praktikum pertemuan 10 ini saya menjadi lebih memahami cara membuat database, membuat tabel, mengatur tipe data, serta memeriksa struktur tabel menggunakan phpMyAdmin. Praktikum ini juga membantu saya memahami bagaimana data dari formulir website disimpan ke dalam database.
