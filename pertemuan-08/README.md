Formulir Permohonan Peminjaman Fasilitas Kampus

Deskripsi

Pada pertemuan 08, saya mengerjakan penambahan fitur formulir permohonan peminjaman fasilitas kampus menggunakan HTML, CSS, JavaScript, dan PHP.

Fitur yang Dikerjakan

1. Menambahkan menu navigasi Peminjaman Fasilitas.
2. Membuat formulir permohonan peminjaman fasilitas kampus.
3. Menambahkan kolom:
   - Nama Penanggung Jawab
   - Jenis Fasilitas
   - Tanggal Peminjaman
   - Durasi Peminjaman (jam)
   - Keperluan Peminjaman
4. Menambahkan tombol Kirim dan Batal.
5. Menambahkan validasi formulir menggunakan JavaScript dan PHP.
6. Mengolah dan menampilkan data peminjaman menggunakan PHP.
7. Menggunakan "htmlspecialchars()" untuk mengamankan data yang ditampilkan.
8. Menggunakan Session dan metode Post-Redirect-Get (PRG).

Teknologi yang Digunakan

- HTML
- CSS
- JavaScript
- PHP
- Visual Studio Code
- Laragon
- Git

File yang Digunakan

- "index.php" : halaman utama dan pemrosesan formulir.
- "style.css" : mengatur tampilan halaman.
- "script.js" : validasi formulir menggunakan JavaScript.
- "README.md" : dokumentasi pengerjaan.

Kesimpulan

Saya telah mengerjakan fitur formulir permohonan peminjaman fasilitas kampus dengan menambahkan navigasi, formulir, validasi, dan pemrosesan data menggunakan PHP.
