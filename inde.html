Bukti Belajar P1 Fungsi: dokumentasi capaian pembelajaran P1 1. Konsep Dasar Pemrograman Web Pemrograman web adalah proses membuat website atau aplikasi yang berjalan melalui browser. Konsep utamanya meliputi HTML untuk struktur, CSS untuk tampilan, JavaScript untuk interaksi, serta backend dan database untuk mengolah dan menyimpan data. Semua bagian tersebut bekerja bersama agar menghasilkan aplikasi web yang dapat digunakan oleh pengguna. 2. Arsitektur Klien-Peladen Arsitektur klien-server adalah sistem yang memungkinkan client meminta data atau layanan kepada server, kemudian server memproses permintaan tersebut dan mengirimkan hasilnya kembali kepada client. Dalam pemrograman web, browser berperan sebagai client, sedangkan web server mengolah permintaan dan data. 3. HTTP Request dan Response HTTP Request adalah permintaan yang dikirim oleh client (browser) kepada server untuk meminta data atau layanan. HTTP Response adalah balasan dari server yang berisi hasil dari permintaan tersebut. Keduanya merupakan proses utama dalam komunikasi antara client dan server pada aplikasi web. 4. HTML, CSS, JavaScript, PHP, MySQL HTML, CSS, JavaScript, PHP, dan MySQL merupakan teknologi yang saling melengkapi dalam pembuatan aplikasi web. HTML digunakan untuk membuat struktur halaman, CSS untuk mengatur tampilan, *JavaScript* untuk menambahkan interaksi, PHP untuk memproses data di sisi server, dan MySQL untuk menyimpan serta mengelola data. Dengan kombinasi tersebut, dapat dibangun website yang interaktif, dinamis, dan terhubung dengan database. 5. Hubungan Antarteknologi Hubungan antar teknologi dalam pemrograman web bersifat saling melengkapi. HTML membangun struktur, CSS mengatur tampilan, JavaScript memberikan interaksi, PHP memproses data, dan MySQL menyimpan data. Dengan bekerja bersama, teknologi tersebut dapat menghasilkan website yang dinamis, interaktif, dan fungsional. Prinsip: README.md root = identitas dan gambaran umum repository.
