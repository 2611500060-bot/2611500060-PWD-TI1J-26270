# pertemuan-04# Pertemuan 4 – CSS3 Layout dan Responsive Web Design

## Implementasi

Navigasi halaman ditata menggunakan Flexbox agar elemen lebih terstruktur. Arah susunan dibuat vertikal, lalu posisi dan jarak antaritem diatur dengan properti perataan dan `gap`. Saya juga menyesuaikan spasi daftar, menghilangkan bullet, serta mengatur tampilan tautan navigasi melalui selector `nav a`.

Perubahan sudah di-commit dan berhasil dikirim ke repository GitHub.

## Pemeriksaan Tampilan

Pada layar ponsel berukuran 375 × 667 piksel maupun layar desktop 1366 × 768 piksel, menu tetap tersusun vertikal dan halaman tampil dengan baik. Setelah aturan CSS navigasi disesuaikan, tidak ditemukan galat. Validasi CSS juga selesai tanpa masalah.
